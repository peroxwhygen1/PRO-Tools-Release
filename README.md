## 📌 Про проект

**UG Admin Tools** — це високотехнологічний та стильний інструментарій, створений для максимального спрощення та прискорення щоденної роботи адміністратора на серверах **Ukraine GTA**. 

Додаток поєднує в собі автоматичний парсинг ігрових логів, плаваючі скляні оверлеї поверх гри, інтелектуальну систему біндів, облік ігрової статистики та сучасний темний Glassmorphism-інтерфейс.

---

## ✨ Ключові можливості та переваги

### 💬 1. Інтелектуальний парсер репортів
- **Миттєве виявлення скарг:** Автоматично зчитує нові репорти від гравців прямо з ігрового логу у реальному часі.
- **Відстеження статусів:** Відображає, чи репорт новий, чи його вже обробляєте ви або ваші колеги.
- **Швидкі дії:** Відповідь у `/pm`, перехід у стеження `/sp` або телепорт `/pwarp` в 1 клік.

### ⚡ 2. Гнучка система біндів та команд
- **Швидкі відповіді та консоль:** Призначення зручних гарячих клавіш для будь-яких відповідей гравцям або адмін-команд.
- **🌐 Потужні Global-бінди (Ланцюжки F8):** 
  - Можливість налаштування ланцюжків з декількох повідомлень поспіль за один бінд.
  - Автоматичне відправлення через F8-консоль з розумним додаванням префіксів.
  - Захисні вікна підтвердження для уникнення випадкових натискань.

### 💎 3. Прозорі скляні оверлеї (Overlay Panels)
- **Підказки поверх гри:** Компактні плаваючі вікна з активними репортами та гарячими клавішами біндів прямо під час гри.
- **Клік наскрізь (Click-Through):** Вікна оверлею не заважають ігровому процесу та дозволяють вільно натискати будь-які кнопки гри під ними.
- **Зручне налаштування:** Легке перетягування та вимкнене прилипання Windows Snap Assist.

### 🔍 4. Пошук та інспекція гравців
- **Офіційний онлайн-пошук:** Пошук інформації про будь-якого гравця за Нікнеймом або ID.
- **Універсальні покарання:** Швидка видача мутів, джайлів та попереджень за шаблонами з авто-визначенням стану гравця (Онлайн / Оффлайн).

### 📊 5. Автоматична статистика та облік часу
- **Точний таймер сесії:** Запис чистого часу активної гри та часу роботи у панелі.
- **Підрахунок репортів:** Автоматичний облік кількості успішно закритих вами репортів за добу.
- **Збереження даних:** Автоматичний запис щоденної статистики для звітів.

### 🔄 6. Безшовне Автооновлення в 1 клік
- **Автоматична перевірка:** Додаток сам сповіщає про вихід нових версій.
- **Збереження налаштувань:** Ваші бінди та статистика **ніколи не видаляються** при оновленні.
- **Монолітна Single-File структура:** Один компактний `.exe` файл без сотень системних бібліотек.

## 🛠️ Встановлення та запуск

1. Перейдіть у розділ **[Releases](https://github.com/peroxwhygen1/PRO-Tools-Release/releases)**.
2. Завантажте останній ZIP-архів `UG_Admin_Tools_v1.0.9.3_Setup.zip`.
3. Розпакуйте файл у будь-яку зручну папку.
4. Запустіть **`UkraineGTA_AdminPanel.exe`**.

## 🎨 Інтерфейс додатка

- **Дашборд:** Головне вікно зі статистикою дня, швидким статусом гри та списком останніх оновлень.
- **Бінди і команди:** Управління відповідями репортів, консольними командами та Global-ланцюжками.
- **Скарги:** Зручний центр обробки усіх надхідних репортів.
- **Гравці:** База даних, пошук та панель швидких покарань.
- **VIP-Чат:** Моніторинг VIP-чату та автоматичний детектор порушень (лайка, реклама, Caps Lock).
- **Налаштування:** Вибір сервера Ukraine GTA, гарячі клавіші та перевірка оновлень.
